# BlueMeter UI 规范

本文定义一期主窗口、设备列表、状态文案、托盘菜单与无障碍要求。实现时优先使用 WPF-UI 提供的资源键与控件，不硬编码颜色。

---

## 1. 视觉方向

- **Fluent / Windows 11**：Mica 背景、圆角、克制的层次、系统强调色。
- **安静的工具**：不做仪表盘，不做大色块；电量是主角，状态是配角。
- **诚实的状态**：读不到就是读不到；旧值必须带“暂时不可达”与时间。
- **传输不混淆**：2.4G 接收器显示为“2.4G 接收器”，绝不标成 BLE 或经典蓝牙；未确认的 2.4G/USB 设备不显示。
- **一屏完成**：不引入多级导航；设备列表 + 设置面板即可。
- **系统优先**：主题、对比度、DPI、动画偏好全部跟随 Windows。

关键词：轻、静、清楚、可信。

标题栏要求：

- 关闭按钮行为是“隐藏到托盘”，不是退出；这是产品约定，需在首次使用引导或 README 中说明。
- 最大化的窗口内容仍保留 8px 内边距，避免贴边。

### 3.1 头部摘要（72px）

- 左侧标题：`设备电量`，20px Semibold。
- 右侧摘要：`{N} 个设备 · 最低 {X}%`，14px；无数据时 `正在扫描…`。当前轻量列表还会分别显示 `BLE` / `经典蓝牙` / `2.4G` 数量。
- 副标题：`已配对设备与 2.4G 接收器 · {间隔} 秒自动刷新 · 上次扫描 HH:mm:ss`，12px，Secondary 色。
- 摘要中的最低值只统计 `Ok` 状态；没有可用值时显示 `--`。
- 扫描进行中，标题右侧显示 16px `ui:ProgressRing`，不替换摘要文字。

### 3.2 设备列表

- 使用 `ItemsControl` + `ui:DynamicScrollViewer`（或 `ListBox` 定制容器），隐藏水平滚动条。
- 行高 68px，行间距 4px，左右内边距 16px。
- 行悬停：`ControlFillColorSecondaryBrush`，圆角 8。
- 行不可选中（无详情页）；键盘仍可聚焦以读取无障碍信息。
- 列表底部留 12px 空白，避免最后一行贴住底栏。
- 主滚动区域使用 Fluent 细滚动条。

### 3.3 底栏（44px）

- 左侧状态：`● 自动刷新已开启` / `● 自动刷新已暂停（蓝牙关闭）`，12px。
- 右侧按钮：`设置`（次要样式）、`立即刷新`（默认样式，扫描中变为“正在刷新…”并禁用）。
- 窗口宽度 < 640 时，左侧文字可截断，按钮不换行。

## 4. 设备列表项

### 4.1 解剖

```text
┌─────────────────────────────────────────────────────────────────┐
│ ┌────┐  鼠标                                    ███████░  15%  │
│ │icon│  BLE · 3 分钟前 · 电量低                              │
│ └────┘                                                          │
└─────────────────────────────────────────────────────────────────┘
  40px   自适应                                      120px    56px
```

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 图标 | 设备类型图标，40×40 圆角容器 | 背景 `ControlFillColorSecondaryBrush`；图标 20×20 |
| 名称 | 设备名 | 14px Semibold；超长省略号；最大 1 行 |
| 元信息 | 类型 + 更新时间 + 状态 | 12px Secondary；最多 1 行；用 `·` 分隔 |
| 2.4G 元信息 | `2.4G 接收器 · {厂商} · 已连接 · 刚刚更新` | 厂商为 Rapoo 或 LINGBAO；不得写成 BLE/经典蓝牙 |
| 电量条 | 120×8 圆角 | 仅在有电量时显示；无值隐藏并保留空间 |
| 百分比 | `15%` | 16px Semibold，右对齐，固定宽度 56，避免跳动 |

### 4.2 设备类型图标

按设备类别映射；无法判断时使用通用蓝牙图标：

| 类别 | 图标语义 |
| --- | --- |
| 鼠标 | 鼠标 |
| 键盘 | 键盘 |
| 耳机/音箱 | 耳机 |
| 手柄 | 游戏手柄 |
| 手机/平板 | 手机 |
| 其他 | 蓝牙 |

优先级：`System.Devices.Aep.DeviceCategory` / BLE Appearance → 名称关键词（Mouse/Keyboard/Headset/Gamepad/Phone）→ 通用图标。图标仅辅助识别，不能作为唯一信息。

### 4.3 排序

每轮扫描结束后重新排序，读取过程中不实时跳动：

1. 低电量（`≤ threshold`）优先，按电量升序。
2. 警告区（`threshold < x < threshold + 20`），按电量升序。
3. 正常（`≥ threshold + 20`），按电量升序。
4. 暂时不可达但有旧值。
5. 不支持/无数据。

同组内按名称做稳定的不区分大小写排序。用户手动刷新时不改变排序规则。

### 4.4 行状态

| 状态 | 行外观 | 电量 | 元信息 |
| --- | --- | --- | --- |
| 正常 | 默认 | 实色 | `BLE · 刚刚` |
| 低电量 | 3px 左侧危险色竖条 + 危险色 8% 背景 | 危险色 | `BLE · 3 分钟前 · 电量低` |
| 不可达（Stale，有旧值） | 整行 72% 不透明度 | 旧值 + 状态点 | `BLE · 暂时不可达 · 5 分钟前` |
| 不可达（Unavailable，无值） | 默认 | `--` | `BLE · 暂时不可达` |
| 不支持 | 默认 | `--` | `经典蓝牙 · 不支持电量读取` |
| 2.4G 正常 | 默认 | 实色 | `2.4G 接收器 · Rapoo/LINGBAO · 刚刚更新` |
| 2.4G 不可达 | 默认 | `--`/旧值 | `2.4G 接收器 · 暂时不可达` |
| 2.4G 充电中 | 默认 | 实色 + 闪电小图标 | `2.4G 接收器 · LINGBAO · 刚刚更新 · 充电中` |
| 读取中 | 默认 | 旧值或 `--` | `正在读取…` |
| 充电中 | 默认 | 实色 + 闪电小图标 | `BLE · 刚刚 · 充电中` |

低电量行必须同时具备：颜色、左侧竖条、文字“电量低”（或警告图标），不能只靠红色。

## 5. 电量条

自绘 `BatteryBar`（`Controls/BatteryBar.xaml`）：

- 尺寸：宽 120，高 8；圆角 4。
- 轨道：`ControlStrongFillColorDefaultBrush`（透明度 0.55），保证在 Mica / 卡片背景上仍能看出槽形。
- 填充：宽度 = `Value / 100 × 120`，`Value` 钳制 0–100。
- 圆角归属：左端圆角由填充自身提供（`CornerRadius="4,0,0,4"`），未满 100% 时切断处为直角；满电时四角归圆，避免盖住轨道右半圆。
- 只有“网格列（120）+ 控件（120）+ 右对齐”，控件不得再加右外边距：多出的外边距会让控件向左溢出并被列边界裁掉，左端圆角会看起来变成直角。
- 颜色阈值（`threshold` 取自设置，默认 20）：
  - `value ≤ threshold`：`SystemFillColorCriticalBrush`（红）
  - `threshold < value < threshold + 20`：`SystemFillColorCautionBrush`（黄）
  - `value ≥ threshold + 20`：`SystemFillColorSuccessBrush`（绿）
- 阈值 20% 时即：≤20 危险、21–39 警告、≥40 正常。
- 行高亮与“电量低”文案使用同一个 `threshold`，保证颜色与语义一致。
- `Value` 变化时 150ms 缓动；系统关闭动画或高对比度时立即切换。
- 无电量时不显示填充，仅保留轨道或整条隐藏（推荐隐藏，避免误读为 0%）。
- 无障碍：`AutomationProperties.Name="电量 15%"`，`HelpText="电量低"`。

> 不使用标准 `ProgressBar` 的原因：Fluent 默认高度、内边距与圆角不适合 8px 电池条；自绘更可控。

## 6. 状态与空页面

### 6.1 首次加载

```text
        ◌  正在扫描蓝牙与 2.4G 设备…
            通常只需要几秒钟
```

- 居中 `ui:ProgressRing`，24px。
- 不使用骨架屏，避免列表闪烁。
- 扫描超过 10 秒仍在进行：追加“设备较多时可能需要更久”。

### 6.2 空状态（无已配对设备）

```text
        [蓝牙图标]
        没有找到蓝牙或 2.4G 设备
        请先在 设置 → 蓝牙和设备 中完成蓝牙配对，或插入已确认的 Rapoo / LINGBAO K98 2.4G 接收器。
        [打开蓝牙设置]
```

- 副标题最多两行，居中，Secondary 色。
- “打开蓝牙设置”调用 `ms-settings:bluetooth`。
- 不显示“重试”大按钮；底部“立即刷新”已足够。

### 6.3 蓝牙关闭 / 无适配器

- 在列表区域显示 `ui:InfoBar`（Severity=Warning）：
  - 蓝牙关闭：`蓝牙已关闭。打开系统蓝牙后会自动恢复扫描。` + 操作“打开蓝牙设置”。
  - 无适配器：`未检测到蓝牙适配器。2.4G 接收器仍会继续尝试读取。`
- 保留上一次设备列表（灰显），不要清空，避免用户误以为设备丢失。

### 6.4 部分不可达

- 不弹全局错误。
- 头部摘要下方显示 12px 提示：`2 个设备暂时不可达`。
- 对应行按 4.4 展示。

### 6.5 扫描失败

- `ui:InfoBar`（Severity=Error）：`本轮扫描失败，将在 45 秒后重试。`
- 提供“重试”操作；不自动打开对话框。
- 连续失败 3 轮才显示；偶发失败仅记录日志，避免闪烁。

## 7. 设置面板

设置以内联面板呈现，不新开窗口，避免额外生命周期。

- 入口：底栏“设置”按钮；再次点击收起。
- 面板位于列表与底栏之间，高度约 200px；出现时列表高度收缩，窗口尺寸不变。
- 面板背景 `CardBackgroundFillColorDefaultBrush`，圆角 8，内边距 16。
- 两列布局；窄窗口（< 640）改为单列，面板内部滚动。
- `Esc` 优先关闭设置面板；面板关闭时再按 `Esc` 才隐藏窗口。

控件与文案：

| 设置 | 控件 | 默认 | 说明 |
| --- | --- | --- | --- |
| 自动刷新间隔 | `ComboBox`：30 / 45 / 60 秒 | 45 秒 | 修改后立即重启计时器 |
| 低电量阈值 | `Slider` 5–50 + 数值 | 20% | 拖动时实时显示数值，松开后保存 |
| 低电量通知 | `ui:ToggleSwitch` | 开 | 关闭后不再弹气泡，列表仍高亮 |
| 启动时最小化到托盘 | `ui:ToggleSwitch` | 关 | 下次启动生效 |
| 开机启动（可选） | `ui:ToggleSwitch` | 关 | 写入 HKCU Run；未实现时隐藏此项 |
| 显示不支持电量的设备 | `ui:ToggleSwitch` | 开 | 关闭后隐藏 `NotSupported` 行 |

- 设置即时保存，不设“保存”按钮。
- 保存失败：`InfoBar` 提示“设置未能保存”，保留当前界面值并记录日志。
- “开机启动”在非 Windows 或写入失败时禁用并显示说明，不弹模态框。

## 8. 托盘

### 8.1 图标

- 使用 `Assets/BlueMeter.ico`，16/20/24/32 多尺寸。
- 一期不随电量变色（避免额外图标资源与视觉噪音）；低电量依靠气泡与主窗口。
- 始终可见，包括主窗口打开时。
- ToolTip 上限 120 字符，超出截断。

### 8.2 右键菜单

```text
┌──────────────────────┐
│ 显示主窗口            │  ← 默认项（加粗）
│ 立即刷新              │
│ ──────────────────── │
│ 退出                  │
└──────────────────────┘
```

- 菜单项高度 32，左侧可选图标；分隔线使用 Fluent 样式。
- 扫描中“立即刷新”禁用，文案变为“正在刷新…”。
- “退出”与其它项之间必须有分隔线，避免误点。
- 菜单支持键盘：方向键移动，Enter 执行，Esc 关闭。
- 菜单不使用 WinForms `ContextMenuStrip`；使用 WPF `ContextMenu` + WPF-UI 样式。

### 8.3 ToolTip 文案

| 场景 | 文案 |
| --- | --- |
| 单设备有电量 | `鼠标 15%` |
| 多设备有电量 | `3 个设备，最低 15%` |
| 单设备仅旧值 | `鼠标 15%（暂时不可达）` |
| 多设备仅旧值 | `3 个设备，最低 15%（旧值）` |
| 有设备但都不可读 | `BlueMeter · 未发现可读电量` |
| 无已配对设备 | `BlueMeter · 未发现蓝牙或 2.4G 设备` |
| 首轮扫描中 | `BlueMeter · 正在扫描…` |

- 单行；设备名超过 24 字符截断。
- 不使用 emoji；避免不同系统字体渲染差异。
- 相同文案不重复写回，减少 Shell 调用。

### 8.4 低电量气泡

```text
BlueMeter
鼠标电量低：15%
```

多设备：

```text
BlueMeter
2 个设备电量低，最低：键盘 12%
```

- 图标：`NotificationIcon.Warning`。
- 每台设备每个放电周期只提醒一次；同轮合并为一条。
- 点击气泡不打开主窗口（H.NotifyIcon 默认行为）；如需点击跳转，二期再加。
- 系统通知关闭/专注助手拦截时不重试。

## 9. 交互与键盘

| 操作 | 行为 |
| --- | --- |
| 单击托盘图标 | 显示并激活窗口；最小化则还原为 Normal |
| 双击托盘图标 | 与单击一致（不额外切换） |
| 关闭窗口 | 隐藏到托盘，显示一次性提示（首次） |
| 最小化窗口 | 保留在任务栏；托盘仍可见 |
| `Esc` | 先关设置面板；再按隐藏窗口到托盘 |
| `F5` | 立即刷新 |
| `Ctrl+,` | 打开/关闭设置面板 |
| `Tab` | 焦点顺序：设置 → 立即刷新 → 列表行 → 设置控件 |
| 列表行 `Enter` | 无操作（一期无详情）；不弹窗 |
| 底栏“立即刷新” | 触发手动刷新；扫描中禁用 |

首次关闭到托盘时，可显示一次托盘气泡：`BlueMeter 仍在后台运行，可从托盘图标重新打开。` 仅一次，记录在设置中。二期可加。

> 一期中文硬编码可接受；文案集中到 `Strings` 静态类，便于二期资源化。

## 11. 颜色与主题

- 只使用 WPF-UI / WinUI 资源键，不写死 `#RRGGBB`：

| 用途 | 资源键 |
| --- | --- |
| 主文本 | `TextFillColorPrimaryBrush` |
| 次要文本 | `TextFillColorSecondaryBrush` |
| 三级文本 | `TextFillColorTertiaryBrush` |
| 卡片背景 | `CardBackgroundFillColorDefaultBrush` |
| 卡片描边 | `CardStrokeColorDefaultBrush` |
| 控件背景 | `ControlFillColorDefaultBrush` |
| 控件悬停 | `ControlFillColorSecondaryBrush` |
| 强调 | `AccentFillColorDefaultBrush` |
| 成功/正常 | `SystemFillColorSuccessBrush` |
| 警告 | `SystemFillColorCautionBrush` |
| 危险 | `SystemFillColorCriticalBrush` |
| 危险浅背景 | `SystemFillColorCriticalBackgroundBrush` |
| 警告浅背景 | `SystemFillColorCautionBackgroundBrush` |

- 明暗主题由 `SystemThemeWatcher` 切换；控件颜色自动跟随。
- 电量条固定使用绿 / 黄 / 红三档（`SystemFillColorSuccessBrush` / `Caution` / `Critical`），不跟随强调色：强调色在深色 Mica 上对比不足，且颜色本身要能表达电量。
- 高对比度模式下，自定义背景与描边可能被系统覆盖；确保文字与图标仍可见，低电量仍显示文字标签。
- 不透明背景兜底：当 Mica 不可用时，使用 `ApplicationBackgroundBrush`，不假设桌面透出。

## 13. 动效

- 电量条数值：150ms `CubicEase`。
- 设置面板展开/收起：200ms 高度/透明度；不使用弹跳。
- 列表排序：仅每轮结束后一次布局变化；不做逐行飞入。
- 加载进度环：系统默认旋转。
- 尊重 `SystemParameters.ClientAreaAnimation` 与高对比度；关闭动画时全部即时切换。
- 不添加持续闪烁/脉冲效果。

## 14. 无障碍

- 每个列表行设置 `AutomationProperties.Name`：
  `鼠标，电量 15%，电量低，3 分钟前更新`。
- 电量条设置 `AutomationProperties.Name="电量 15%"`；自定义控件需实现 `AutomationPeer` 或设置附加属性。
- 纯图标按钮（刷新、设置）必须有 `ToolTip` 与 `AutomationProperties.Name`。
- 焦点矩形清晰可见；不使用 `FocusVisualStyle={x:Null}`。
- 点击目标 ≥ 32×32；列表行整行可聚焦。
- 不用颜色作为唯一状态：低电量有文字标签，不可达有状态点 + 文本。
- 高对比度下验证：低电量背景、描边、电量条填充、InfoBar。
- 屏幕阅读器顺序：标题 → 摘要 → 列表（逐行）→ 底栏。
- 键盘可完成：刷新、开关设置、退出（托盘菜单）。

## 15. 缩放与响应式

- 支持 100%–200% 系统缩放；使用设备无关单位，图标使用矢量或高分辨率 ICO。
- 窗口宽度 < 640：
  - 头部摘要换行或缩写为 `3 台 · 最低 15%`；
  - 设备元信息可截断；
  - 设置面板改单列并内部滚动。
- 高度 < 520：列表最小高度 160，设置面板可滚动。
- 多显示器：窗口在鼠标所在屏幕居中；不使用固定屏幕坐标。
- 不因 DPI 变化重建窗口；WPF 自动缩放。
